# Thread Overview

A read-only BB plugin for developers working with coding agents. It puts a compact
thread summary beside the conversation: results, uncommitted changes, subagents,
background tasks and sources. The visual reference is the user's Codex sidebar.

Users open the overview from the thread header or right-panel launcher, inspect
status, open files and websites, follow child threads, and review a file diff.
There is no separate dashboard, setup, account, or mutation workflow.

Use BB's native panel layout, theme tokens, icons, file links and diff renderer.
UI copy is Russian for the requested surface. Respect provider reporting limits;
show empty, partial-history, loading and recoverable error states honestly.
