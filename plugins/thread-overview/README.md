# Thread Overview

Компактный обзор треда в правой панели bb, по образцу бокового блока Codex.
Нажмите **Обзор** в заголовке треда или выберите **Обзор** в меню новой вкладки
правой панели. На узком экране кнопка отображается значком.

- **Результаты** — файлы хранилища треда и изображения, опубликованные провайдером.
- **Изменения** — незакоммиченные изменения окружения; нажатие открывает штатный diff.
- **Субагенты** — дочерние треды и делегированные задачи из истории, со статусами. Нажатие открывает историю рядом с чатом; модель и reasoning показаны, когда они доступны.
- **Фоновые процессы** — задачи, которые провайдер сообщает как backgroundTask.
- **Источники** — вложения, прочитанные файлы, открытые сайты и поисковые запросы.

Файлы открываются штатным просмотрщиком bb, сайты — согласно настройкам браузера bb.
Списки сворачиваются после шести строк. Обзор заполняет правую панель без вложенной карточки. Цвета, шрифт и плотность списков следуют bb. Служебные имена субагентов приведены к читаемому виду; сообщения оформлены штатным Markdown, действия сгруппированы, команды и вывод используют просмотрщик кода bb. Завершение отмечается значком, без повторяющихся текстовых статусов.
Обзор обновляется каждые 10 секунд, пока панель открыта и окно видно;
есть ручное обновление. Запросы отменяются при закрытии и смене треда.

## Установка из этой коллекции

```sh
bb plugin install path:. --plugin thread-overview
```

## Разработка

```sh
npm run typecheck --workspace=bb-plugin-thread-overview
npm test --workspace=bb-plugin-thread-overview
npm run build --workspace=bb-plugin-thread-overview
```

## Границы данных

Используется публичный SDK bb 0.6.15. Плагин не читает внутренние базы bb,
не запускает команды, не меняет файлы и не отправляет сообщения.
Хранилище треда и timeline не являются полным индексом всех созданных файлов:
файлы рабочего каталога появятся в результатах только как опубликованные изображения.
Вложения из `Attachments/` относятся к источникам.

Запросы ограничены 200 файлами, 100 сегментами истории, 100 событиями задач
и 100 дочерними тредами. При достижении границы отображается уведомление.
Источники и делегированные задачи отражают загруженную часть истории.
Провайдеры не всегда публикуют именованные фоновые задачи: тогда доступен
счётчик активных команд bb. Это не монитор всех процессов операционной системы.
При ошибке отдельного запроса остальные разделы остаются доступны.

Для тредов bb модель и reasoning берутся из resolved execution options. Для нативных
делегаций — из явных аргументов связанного вызова, если они есть в публичной истории.
Модель родителя не подставляется за неизвестную модель субагента.
