Distinguish projects at a glance with a small color accent. Project Themes adds
muted tints to your current light or dark bb theme.

## What you can customize

- Project rows in the standard thread list.
- The bb favicon in external browsers and internal Browser tabs.
- The workspace and sidebar background.

Each project has one shared color, with independent toggles for each element.
Choose from eight muted presets, from sage to lavender, or use the native color
picker. A compact preview shows the combination before you save.

## How it works

Open Settings → Project Themes → Project colors, select a project, choose which
elements to tint, and click Save. Settings are stored on the bb server and synced
across windows. Reset restores defaults for the selected project only.
All elements are enabled by default.

## Requirements and limitations

Requires bb 0.45+ and a compatible Plugin SDK version starting at 0.6.15.
No external services or accounts are needed. External browser tabs use a colored
bb favicon; their system chrome remains controlled by the browser. In split views,
the background follows the current route's project. Thread tinting targets the
standard thread list; selectors may need updating if bb's DOM changes.
