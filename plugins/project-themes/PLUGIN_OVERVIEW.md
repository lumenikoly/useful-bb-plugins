Проекты легче различать, когда у каждого есть небольшой цветовой акцент.
Project Themes добавляет спокойные оттенки поверх текущей светлой или тёмной темы bb.

## Что можно настроить

- Строки проекта в стандартном списке тредов.
- Иконку bb на вкладке внешнего браузера и внутренние вкладки Browser.
- Фон рабочей области и боковой панели.

У проекта один общий цвет; каждый элемент включается отдельно. Выберите один из восьми
приглушённых оттенков — от шалфея до лаванды — или откройте системную палитру.
Небольшой предпросмотр показывает сочетание перед сохранением.

## Как пользоваться

Откройте Settings → Project Themes → Цвета проектов, выберите проект,
включите нужные элементы и нажмите «Сохранить». Цвета хранятся на сервере bb
и синхронизируются между окнами. «Сбросить» возвращает настройки
по умолчанию только выбранного проекта. Изначально все элементы включены.

## Требования и ограничения

Нужен bb 0.45+ с совместимым Plugin SDK 0.6.15+. Внешние сервисы и аккаунты
не требуются. Системная рамка вкладки браузера не окрашивается — меняется иконка bb.
В разделённом экране фон следует проекту текущего маршрута. Окраска строк рассчитана
на стандартный список тредов; при изменении DOM bb селекторы могут потребовать обновления.
